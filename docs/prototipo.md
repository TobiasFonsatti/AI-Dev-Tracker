**Link do protótipo:** `[preencher com o link do Figma/Penpot, com acesso de visualização liberado]`

> O protótipo em si precisa ser montado em uma ferramenta de design (Figma ou Penpot) e ser
> navegável — clicável entre telas, não uma sequência de imagens soltas. A tabela abaixo é o
> índice que acompanha esse link e cobre as telas das histórias Must do backlog (E2a).

| Tela | Perfil | História relacionada (E2) | O que a tela mostra/permite |
|---|---|---|---|
| Login / Cadastro | Todos | #1 | Formulário de e-mail e senha; erro de login genérico, sem indicar qual campo está incorreto |
| Meus projetos | Desenvolvedor | #2 | Lista de projetos do desenvolvedor, botão para criar novo projeto (nome, descrição) |
| Detalhe do projeto / tarefas | Desenvolvedor | #3 | Lista de tarefas do projeto com status (a fazer / em andamento / concluída), botão para nova tarefa |
| Nova sessão de desenvolvimento | Desenvolvedor | #7 | Formulário com projeto, tarefa, data, duração, campo "usou IA?" que revela ferramenta e tipo de atividade quando marcado |
| Avaliação da sessão | Desenvolvedor | #8, #9 | Escalas de 1 a 5 para produtividade, dificuldade, confiança, foco, fluidez e qualidade do feedback; campo de observações opcional |
| Meu histórico e indicadores | Desenvolvedor | #11 | Lista de sessões filtrável por projeto e período; indicadores pessoais (uso de IA, confiança média, dificuldade média) |
| Gestão de usuários | Administrador | #4 | Lista de usuários com opções de criar, editar e desativar conta |
| Permissões por perfil | Administrador | #5 | Tela de configuração das permissões associadas a cada perfil (Desenvolvedor, Gestor/Professor, Administrador) |
| Catálogo de ferramentas de IA | Administrador | #6 | Lista de ferramentas com opções de adicionar, editar e desativar |
| Dashboard da equipe | Gestor/Professor | #12, #13 | Indicadores agregados (sessões, ferramentas mais usadas, médias de produtividade/confiança), com filtros por projeto, desenvolvedor e período |
| Situações de atenção | Gestor/Professor | #10, #14 | Lista de desenvolvedores com situações de atenção ativas, motivo, data de identificação e botão para marcar como "acompanhada" |
| Evolução dos indicadores | Gestor/Professor | #15 | Gráfico de série temporal de um indicador (ex.: confiança média) com período configurável |
