## Stack

- Frontend: Next.js (React + TypeScript)
- Backend: Next.js (API routes) + Prisma ORM
- Banco de dados: PostgreSQL
- Autenticação: em decisão entre Auth.js e Supabase Auth (ver [Termo de Aceite](docs/termo-de-aceite-projeto.md))
- Deploy: Docker em servidor próprio (Oracle Cloud), exposto via Cloudflare Tunnel
